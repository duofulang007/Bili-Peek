| 问题 | 修复及验证 |

| 翻译模型未来版本可能绕过固定摘要校验，ZIP 盘符路径可逃出目录 | 只安装已固定摘要的 1.9 模型；每个解压目标解析后必须位于模型目录内。离线测试覆盖不同盘符路径、错误摘要和正常安装。 |
| 页面验收误把实际状态文字占位算成空悬停详情占位 | 验收纳入实际状态区高度，仍单独检查悬停详情为绝对定位、隐藏后不占高度；未修改图表布局。 |

- 浏览器：路由切换、媒体定位、图表加载失败、选区与画质、保存表单、任务轮询、字幕读取、观看记录和最新笔记链接。
- 助手：本机监听、Host / Origin / 配对校验、请求大小、任务去重与并发、取消与提交阶段、仓库路径及链接、成品排他写入、失败清理与真实媒体核验。
- 下载与缓存：Range 响应检查及拒绝重定向、索引范围、备用源一致性、部分缓存摘要、暂停与取消、活动缓存保护、容量预留和超预算临时目录。
- 插件：字幕及识别稿读取、原文与译文切换、搜索与高亮、播放跟随、个人笔记冲突检查及异步保存。
