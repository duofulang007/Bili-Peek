# Bili-Peek

用于 Edge / Tampermonkey 的 B 站视频观看助手。当前版本 **0.3.20**。

视频右侧展示词云与弹幕密度图，支持词语联动、点击定位、观看区间记录和片段选取；配合本地助手，可将带声音的视频片段与字幕原文保存到 Obsidian。无需 AI 服务。

## 安装用户脚本

1. 在 Edge 安装 Tampermonkey。
2. 打开 [Bili-Peek.user.js](Bili-Peek.user.js)，复制全部内容，在 Tampermonkey 中新建脚本并保存。升级时替换旧脚本，避免同时启用两份。
3. 刷新普通 B 站视频页，按提示允许访问 `api.bilibili.com`。

仅观看双图时不需要 Node.js、本地助手或 FFmpeg。脚本仅匹配 `https://www.bilibili.com/video/*`，不支持直播、番剧和互动视频分支。UP 信息上移，推荐视频保留并下移；两张图与播放器上下边缘对齐，全屏时隐藏。

## 图内操作

- **词云**：切换“高频词 / 重复短语”。点击词语，在密度图中用橙线标出出现时段；再次点击或清除可恢复。候选最多 80 项，实际显示数量随图框大小调整。
- **密度图**：悬停查看时间桶、弹幕数和最多三条不同原文；点击定位视频，保持播放或暂停状态。左右键选择位置，回车跳转。
- **观看记录**：灰蓝细线表示累计实际观看区间，小圆点表示本次起点，虚线表示当前播放位置。暂停、缓冲和跳过部分不计入观看。按视频与分 P 保存在油猴本地数据中，最多保留 200 项。
- **截取选区**：拖动左右把手调整区间，拖动中间整体平移；拖动不改变播放位置。时间框支持秒数、`分:秒` 和 `时:分:秒`，回车或离开输入框应用；悬停滚轮每次调整 1 秒。把手支持左右键，Shift 每次调整 10 秒。
- **保存**：点击保存图标，填写笔记名称、必填标签与选填摘要。已配对时导出视频与笔记，未配对时仅保存本地选区草稿。单次选区最多 30 分钟。

没有弹幕或关闭弹幕的视频仍可定位、选区和保存。请求失败显示错误与重试，不绘制冒充零弹幕的曲线。切换视频或分 P 会取消旧请求并重置选区。

## 保存到 Obsidian

### 首次配置

需要 Windows、可运行的 Node.js、Python（仅用于下载工具）、FFmpeg 与 ffprobe，以及已有的 Obsidian 仓库。项目没有 npm 依赖。

在项目目录执行：

```powershell
python helper/download-tools.py
node helper/configure.cjs
```

下载脚本从 gyan.dev 获取 FFmpeg Windows essentials，并核对发布方 SHA-256，将工具保存到 `.tools/`。

编辑新建的 `.local/export-config.json`，将 `vault` 改为自己的 Obsidian 仓库绝对路径，`output` 改为仓库内的目标笔记目录，确认 `ffmpeg` 和 `ffprobe` 路径正确。配置脚本内的默认仓库路径属于开发者电脑，其他电脑必须修改；保留随机生成的 `token`，不要公开。

启动助手并复制配对码：

```powershell
node helper/start.cjs
powershell -NoProfile -ExecutionPolicy Bypass -File helper/copy-pairing.ps1
```

在 B 站页面打开油猴菜单“配对 Obsidian 片段助手”，粘贴配对码。按提示允许本地地址和字幕域名请求。助手在后台运行，仅监听 `127.0.0.1:18766`，要求配对码，不读取或导出浏览器 Cookie。

项目中的 `启动片段助手.cmd` 是开发者电脑的便捷入口，内含固定 Node 路径；使用前需要改为自己的 `node.exe` 路径。直接执行上述命令也可完成启动与配对。

### 导出行为

保持 B 站登录，选择区间后保存：

- 生成一条 Markdown 笔记和一个带声音的 MP4，媒体放在目标目录的 `Bili-Peek附件/`，同名笔记增加短编号，不覆盖原文件。
- 按播放器当前选择的画质匹配轨道，不设 720p 上限。画质读取失败或对应轨道缺失时提示重试，不自动降级。
- 视频重新编码裁剪，核验音视频轨道、可解码性与时长，存在帧率与音频编码粒度容差。只有源轨道证实到达文件末尾且成品通过核验，才允许按实际末尾时长保存并注明。
- 字幕保留原文与相对片段起点的段首时间，合并碎行但不改写、纠错或生成分析。跨选区整句会明确标注；不生成独立 SRT。
- 缺少字幕或区间无字幕时自动保存视频并在笔记注明，不生成假转录。自动语音转录尚未接入。
- 标签支持 `学习/编程` 层级形式；摘要可留空。失败或取消后，在当前页面重存同一区间会恢复表单草稿；成功后清空。

成功任务的阶段计时保存在 `.local/export-timings.jsonl`，不记录配对码或媒体地址。仅在文件写入成功后提示完成，失败会清理已知暂存文件。

### Obsidian 阅读插件（可选）

配置仓库后执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File helper/install-obsidian-player.ps1
```

脚本将 [obsidian-plugin](obsidian-plugin/) 安装到配置仓库并加入启用列表，随后重新加载 Obsidian。

阅读视图显示上方播放器和下方独立滚动的字幕正文，点击段首时间可跳转本笔记的 MP4，保持播放状态与阅读位置；隐藏重复标题，Markdown 原文不变。仅处理 Bili-Peek 笔记，源码编辑和实时预览暂不支持该布局。

插件运行时，删除片段笔记会检查现存 Markdown、Canvas 与 Base 的引用，将无人引用的 Bili-Peek 视频移入系统回收站。共享视频保留，读取失败则不清理；回收站仍占磁盘空间。

### 登录自启动（可选）

`helper/install-autostart.ps1` 可安装当前用户启动项 `Bili-Peek Helper.vbs`，隐藏启动且不复制配对码。该脚本依赖 Codex 缓存目录下的 Node 路径，使用前应确认或调整。删除启动项即可取消；移动项目后需要重新安装。

## 数据口径与限制

- 先读取匹配当前视频的页面元数据，必要时请求视频信息，再按当前分 P 的 cid 分段读取弹幕。仅覆盖接口返回的可获取弹幕，不代表全部历史弹幕或全部观众。
- 词频为“提及该词的弹幕条数”，同一条内重复提及只计一次，相同文本的不同弹幕分别计数。排除代码/BAS 与非普通池消息。
- 重复短语是至少两条弹幕提及的连续 2–4 个词，使用浏览器中文分词器与少量专业词补充，不是 jieba 或 AI 总结。
- 密度统计全部已取得且落在当前视频时长内的弹幕，桶宽在图内标注。峰值只反映发言数量，不能单独判断情绪或原因。
- 最多缓存三个分 P，五分钟有效，不写入磁盘；超过 12 小时或 15 万条弹幕会提示限制。

## 开发与验证

无第三方 npm 依赖，安装 Node.js 后可直接运行：

```powershell
npm run check
npm test
npm run preview
```

若环境仅提供 `node`，可按 [package.json](package.json) 中的命令直接执行。导出测试会调用项目 `.tools/ffmpeg.exe` 与 `.tools/ffprobe.exe`，需要先准备工具。

预览服务仅监听本机。打开 `http://127.0.0.1:8765/video/BVLocalPreview/`，点击“运行页面验收”。预览使用模拟弹幕、模拟助手与本地静音媒体，不等于 B 站真实页面验证。添加 `?initializing=1&blocked-rail=1` 可检查初始化等待与右侧鼠标事件兼容。

2026-10-03 首次 Git 提交前复测：语法检查与 31 项 Node 测试全部通过，包含实际媒体裁剪与导出核验。历史记录中另有 56 项本地页面验收和 50 组词频与短语一致性核对，本次未重新运行浏览器验收。真实页面的图表定位曾由用户确认恢复；当前完整登录 Edge/油猴导出字幕与 Obsidian 阅读链路仍需真实环境验收，不能以模拟页面代替。

```powershell
node tests/benchmark-wordstats.cjs
node helper/benchmark-export.cjs
```

基准使用本地合成数据，不代表 B 站网络或整体页面速度。0.3.20 复用短语子串索引和时间桶原文示例，减少重复统计与悬停扫描，保留统计口径和媒体核验。

出现页面问题时，使用油猴菜单“复制 Bili-Peek 排错信息”。诊断只读，不读取 Cookie、登录凭据或原始弹幕文本，不自动上传。

## 项目结构

| 路径 | 内容 |
| --- | --- |
| `Bili-Peek.user.js` | 用户脚本、双图、选区和助手配对 |
| `helper/` | 本地助手、媒体导出、安装与维护工具 |
| `obsidian-plugin/` | Obsidian 阅读播放器插件 |
| `tests/` | Node 测试、预览与合成数据基准 |
| `docs/`、`初稿方案.md` | 历史设计与概念演示，不代表已实现功能 |

`.local/`、`.tools/`、`node_modules/`、`tests/artifacts/` 与 `tests/export-sandbox/` 已由 `.gitignore` 排除，包含配对配置、工具或生成产物，不应提交。
