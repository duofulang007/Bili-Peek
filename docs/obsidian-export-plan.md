# Bili-Peek 视频片段与字幕保存计划

状态：0.3.0 已实现本地助手、网页媒体/字幕获取、裁剪与仓库写入。18 项核心/导出测试和 30 项页面验收通过。真实公开 B 站视频裁剪及目标仓库写入已验证；真实测试视频字幕需要登录，当前 Edge/油猴完整字幕链路及 Obsidian 内播放尚未实测。

## 保存结果

一次保存生成一条 Markdown 笔记、一个带声音的 MP4，以及对应的 SRT 字幕（字幕可取得时）。笔记上方嵌入本地视频，下方放选区字幕原文。记录视频标题、BV/AV、分 P、cid、原视频起止秒数、片段实际时长、字幕来源、创建时间、分类和标签。分类使用属性；附件目录由配置指定，避免改动仓库现有组织。

用户已指定保存目录 `D:\Obsidian仓库\Codex学习\网页内容`，并授权采用方便的方式。采用按需启动的后台助手，无需 Obsidian REST API 插件。配对码由启动器复制到剪贴板；首次通过油猴菜单配对。

## 处理流程

1. 油猴提交保存时的不可变快照：视频标识、分 P/cid、起止时间、标题、分类与标签。提交后切换视频不会改变任务内容。
2. 本地助手核验目标仓库、依赖、范围和视频身份。只处理明确配置的仓库；不接受页面任意指定写入路径。
3. 获取对应分 P 的媒体和字幕。当前实现由油猴请求 B 站接口，浏览器请求签名所需的公开参数，助手计算 WBI 签名；向助手发送媒体地址和字幕正文，不导出登录凭据。不要把播放器的 blob URL 当作可下载的原视频地址。公开视频媒体请求已验证；登录字幕获取待真实页面验收。
4. 使用 FFmpeg 解码裁剪、重新编码为兼容的 H.264/AAC MP4，时间戳从零开始。精确模式不能只依赖关键帧流复制。必要时为裁剪读取更多媒体数据，不能承诺网络只下载选中时段。
5. 使用 ffprobe 核验音视频轨道、可解析性、时长与时间戳；验收容差结合源视频帧率及音频编码时长，不承诺数学意义零误差。
6. 提取与半开区间 `[start, end)` 重叠的字幕句，即 `cue.end > start && cue.start < end`。保留原文及原时间；SRT 裁剪时间为 `max(cue.start,start)-start` 至 `min(cue.end,end)-start`。标明被起点或终点截断的句子。
7. 输出暂存文件并检查后，提交附件，最后提交 Markdown 笔记。任何阶段失败都不显示完整保存成功；附件已经落盘而笔记提交失败时保留可恢复状态供重试。
8. 按视频身份和时间范围生成稳定任务标识，防止连点或重试生成重复笔记。文件名含短标识，不覆盖现有不同内容。
9. 前端显示处理中、完成或失败；完成必须来自助手的实际写入结果。保存按钮继续只显示图标；完成后可通过链接打开 Obsidian 笔记。

## 字幕与无字幕策略

- 原字幕通常按句提供时间，跨边界句无法依据句级时间戳准确删掉区间外的几个字。默认保留并标注；选区字幕时间与原文精度分开说明。
- 若原字幕不可得，显式提供转录选项。转录只处理已裁剪片段；模型与运行方式待确定，不默认上传音频到外部服务。转录文本标注来源，识别准确率不作为保证。
- 无字幕且尚未配置转录时，告知用户字幕缺失；不能悄悄保存空字幕并宣称视频和字幕均已完成。

## 本地助手

按需启动作为初始方案。只监听回环地址，使用配对令牌并检查来源；保存令牌仅留在油猴配置中，不写入导出的笔记。工具使用参数数组调用，不拼接 shell 命令。不自动收集或导出浏览器登录凭据；需要登录时另行确定最小范围的获取方式。

首次配置包含目标仓库、附件目录、默认分类与标签、处理工具路径。系统自启动、额外插件、外部转录服务不作为前置条件。

## 实施顺序与验收

1. 本地文件闭环：测试媒体裁剪 → 时间范围字幕 → 写入专用测试仓库 → 验证 MP4、SRT、笔记和重复保存；覆盖跨边界字幕、末尾选区、磁盘错误与中途退出。
2. 实际 B 站闭环：普通有字幕视频，明确分 P，用当前网页选区保存。验证画面和声音存在、片段起止符合所选范围、字幕无其他分 P 内容、笔记能在 Obsidian 播放。
3. 接入现有图标按钮与进度反馈；覆盖连点、处理途中切换视频、助手未启动和重试。保持现有词云、密度图定位和布局。
4. 最后扩展无字幕转录。所有报告分别说明本地模拟验收与真实 B 站/Obsidian 验收。
